수행평가 진행 방법

원활한 답안 작성과 결과물 저장을 위해 카카오톡 내부 브라우저가 아닌 외부 브라우저에서 접속해 주세요.

  • 아이폰 / 아이패드 : Safari(사파리) 권장
  • 갤럭시 : Chrome(크롬) 또는 삼성 인터넷 권장
  • PC : Chrome(크롬) 또는 Edge(엣지) 권장

카카오톡에서 링크를 받았다면 '다른 브라우저로 열기'를 선택하거나 링크를 복사해 권장 브라우저에서 접속하세요.

※ 브라우저를 변경하면 기존에 작성한 답안이 자동으로 옮겨지지 않을 수 있으므로 가급적이면 처음부터 권장 브라우저를 활용하여 접속해 주세요.

카카오톡 내부 브라우저에서는 파일 다운로드가 제한될 수 있습니다. 이 경우 「파일 공유·저장 (카카오톡용)」 버튼을 눌러 기기의 공유 메뉴에서 파일 저장을 시도하세요. 기기에 따라 지원되지 않을 수 있습니다.

수행평가 저장 및 제출 방법

활동을 마친 후에는 결과물을 PDF 또는 이미지(PNG) 파일로 저장해 주세요.

  • 아이폰 / 아이패드 : Safari의 공유·프린트 기능을 이용해 PDF 저장
  • 갤럭시 : Chrome 또는 삼성 인터넷의 인쇄 메뉴에서 PDF로 저장
  • PC : PDF 저장 버튼을 누르고 'PDF로 저장' 선택

PDF 저장이 되지 않는 경우 이미지(PNG) 파일로 저장하거나 작성한 웹페이지를 직접 캡쳐하여 제출해도 됩니다.

저장한 결과물이 정상적으로 열리는지 확인한 뒤 '한국지리 탐구 오픈 채팅방'에 제출해 주세요.

※ 지각 제출 시 감점이 있으므로 반드시 제출 기한을 지켜 주세요.
